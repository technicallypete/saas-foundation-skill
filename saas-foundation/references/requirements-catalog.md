# Requirements catalog

Every requirement the archetype carries, with its enforcement class and verification. The static suite (`S-TRACE`) checks this table: every T row names a check defined by `validation/run.sh`, every F row names an existing fixture test, every P row names a foundation stage that exists in [../checklists/foundation-follow-up.md](../checklists/foundation-follow-up.md) plus a verification method, and every resource link resolves.

- **T — template-enforced:** rendered by the generator and verified by a named harness check.
- **F — fixture-exercised:** demonstrated by a minimal fixture against real infrastructure or the real SDK, or as a labelled unit test.
- **P — prescribed:** guidance plus a later foundation stage that must implement and verify it. **Not** a passing test.
